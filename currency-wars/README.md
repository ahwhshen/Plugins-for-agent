# currency-wars · 星穹铁道·货币战争

《崩坏：星穹铁道》「货币战争」自动运行插件：窗口定位截图 + OCR/VLM 识别，
按词条规则自动选祝福与投资，带独立控制台窗口。

- **版本**：1.0.0
- **宿主**：[Cyrene-Agent](https://github.com/ahwhshen/Cyrene-Agent)（需启用插件系统）
- **依赖宿主能力**：`gamebot`（清单 `uses` 声明，未提供时插件判空降级）
- **权限声明**：`risk: ["shell"]`（调用本地 OCR 命令需要）

## 功能

- **目标定位**：本地全屏（按进程检测）或窗口模式（按标题，云游戏可用），可选自动启动游戏。
- **识别**：自动探测本地 OCR（Better-HSRCW），未装则回退宿主 VLM 视觉识别；模糊匹配阈值可调。
- **局外阶段**：检测减益、按「目标词条 / 拦截词条 / 投资目标」规则自动选择祝福与投资。
- **局内阶段**：按局内投资目标与策略目标自动决策。
- **组合模式**：局外 + 局内一条龙，主目标 / 拦截 / 投资规则各自可选（命中即停 / 必须命中 / 可选 / 忽略）。
- **控制台窗口**：独立插件窗口（760×580，复用策略），实时查看运行状态。
- **演练模式**：「仅识别不动作」可先验证识别效果再放开自动操作。

## 安装

把本目录整体复制到 `%APPDATA%\live2d-cyrene\plugins\currency-wars\`，
重启应用后在 设置 → 插件 打开开关。

## 目录说明

```
currency-wars/
├── plugin.json     # 插件清单（含全部设置项声明 settingsSchema）
├── icon.png        # 图标
├── lib/            # 编译后的运行时代码（入口 lib/index.js）
├── window/         # 控制台窗口 UI（window/index.html）
└── src/            # TypeScript 源码（含单测），供二次开发参考
```
